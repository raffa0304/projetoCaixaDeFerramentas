# projetoCaixaDeFerramentas
Projeto feito em Python com 3 ferramentas: Uma calculadora de juros simples por dia de atraso, um pequeno sistema de estoque, uma pagina que mostra o calculo de comissão de vendedores.

Para rodar o projeto, no terminal com a pasta em que o projeto está selecionada digite o comando:
streamlit run main.py ou python -m streamlit run app.py o projeto vai rodar
